# NOIR - Streetwear

NOIR is a simple streetwear brand website created using HTML and CSS.

The website focuses on a clean and minimal design inspired by music, art and everyday city life.

## Features

- Home page with a video hero section
- Streetwear collection section
- Product cards with images and prices
- About NOIR section
- Email signup form
- Simple navigation bar
- Responsive design for smaller screens
- Hover effects on buttons and navigation links

## Technologies Used

- HTML
- CSS
